# Clinic Research Pipeline

Полный workflow для сбора всех публичных данных о медицинской клинике (Россия). Стэк-агностично — на выходе JSON и файлы, дальше билдь хоть HTML, хоть React, хоть статичный лендинг.

Документация процесса который реально применялся к клинике АПЕКС (Южное Бутово, Москва). За ~30 минут работы AI-агента собирается ~95% всех публичных данных + 50 фото + 100 отзывов + полный прайс.

## Документы

- **[RESEARCH-WORKFLOW.md](./RESEARCH-WORKFLOW.md)** — главный документ. Пошаговый процесс по 6 источникам с готовым кодом (Playwright JS + Python + Bash).
- **[OUTPUT-SCHEMA.md](./OUTPUT-SCHEMA.md)** — формат итоговых JSON файлов.
- **[scripts/](./scripts/)** — рабочие скрипты которые можно запускать как есть.

## TL;DR — минимальный вход для запуска

Достаточно одного из:
- Yandex Maps URL клиники (рекомендую — золотой источник)
- Название + город
- Старый сайт клиники

## TL;DR — что на выходе

```
research/
├── clinic_data.json          # консолидированные данные (реквизиты, врачи, особенности)
├── reviews_yandex.json       # ~100 уникальных отзывов с Я.Карт
├── photos_yandex.json        # URL ~50 фото с Я.Карт
├── images-yandex/            # скачанные фото (XXXL разрешение)
├── images-old-site/          # фото со старого сайта
├── doctors-prodoctorov/      # квадратные фото врачей (low-res, backup)
└── prices/
    ├── *.xlsx                # оригинальные прайс-листы
    └── all_prices.json       # распарсенные цены
```

## 6 источников по приоритету

| # | Источник | Что даёт уникального | Сложность |
|---|---|---|---|
| 1 | **Yandex Maps** | Рейтинг, отзывы, фотки, услуги, особенности, кэшбэк, награды, телефон актуальный | средняя (SPA + lazy load) |
| 2 | **Старый сайт клиники** | Юр.реквизиты, ИНН, лицензия №, email, прайс-листы xlsx, hi-res фото врачей | низкая |
| 3 | **Prodoctorov** | Стаж врачей в годах (нигде больше нет), образование, квадратные фото | низкая |
| 4 | **2GIS** | Доступная среда (пандус), парковки, отдельная аудитория рейтинга | низкая |
| 5 | **Google поиск** | Discovery всех источников (Zoon, DocDoc, Instagram) | низкая |
| 6 | **Соцсети** (Insta/VK) | Реальные фото пациентов/процедур, недавние акции | средняя |

## Стоимость

- AI агент (Sonnet через Playwright): ~30 минут / ~80-100K токенов / **$1.5-3** на клинику
- Без AI (ручной скрап): ~3-4 часа человеко-часов

## Что НЕ делает этот pipeline

- Не выдумывает данные — если нет в источниках, помечает TBD
- Не лезет в платные базы (только публичные сайты)
- Не парсит CAPTCHA (если попадается — пропускает источник)
- Не использует Yandex/Google API (всё через DOM scraping)
