# Clinic Research Pipeline

Workflow и скрипты для сбора всех публичных данных о медицинской клинике (РФ) из открытых источников. Стек-агностично — на выходе JSON и файлы, дальше билдь хоть HTML, хоть React, хоть статичный лендинг.

За ~30 минут работы AI-агента (Sonnet через Playwright) собирается ~95% публичных данных клиники + ~50 фото + ~100 отзывов + полный прайс. Документация описывает реальный процесс, отработанный на действующей клинике.

## Возможности

- **Discovery источников** — поиск всех публичных страниц клиники (Yandex Maps, 2GIS, Prodoctorov, Zoon, DocDoc, соцсети) одним Google-запросом.
- **Yandex Maps scraping** — Playwright-скрипт тянет данные с org-страницы, прокручивает и дедуплицирует ~100 отзывов, выгружает галерею фото в XXXL-разрешении.
- **Сбор по 6 источникам** — каждый закрывает свой пробел: реквизиты и прайсы со старого сайта, стаж врачей с Prodoctorov, доступная среда с 2GIS, свежие фото из соцсетей.
- **Парсинг прайс-листов** — конвертация xlsx в JSON с разбором цен (диапазоны, варианты, «от N», единицы).
- **Скачивание изображений** — пакетная загрузка фото и портретов врачей по списку URL.
- **Консолидированный вывод** — единый `clinic_data.json` с реквизитами, врачами, услугами, рейтингами и фичами как вход для билда сайта.
- **Без выдумок** — отсутствующие данные помечаются TBD; работа только с публичными сайтами через DOM scraping, без платных баз, CAPTCHA и Yandex/Google API.

## Стек

- **JavaScript (Node.js) + Playwright** — headless-браузер для скрапинга SPA с lazy-load.
- **Python** — `openpyxl` для парсинга xlsx-прайсов, `urllib` для загрузки изображений.
- **Bash** — вспомогательные команды процесса.
- **Формат вывода** — JSON + файлы изображений (стек-агностично).

## Источники по приоритету

| # | Источник | Что даёт уникального | Сложность |
|---|---|---|---|
| 1 | **Yandex Maps** | Рейтинг, отзывы, фото, услуги, особенности, кэшбэк, награды, актуальный телефон | средняя (SPA + lazy load) |
| 2 | **Старый сайт клиники** | Юр.реквизиты, ИНН, лицензия, email, прайс-листы xlsx, hi-res фото врачей | низкая |
| 3 | **Prodoctorov** | Стаж врачей в годах (нигде больше нет), образование, фото | низкая |
| 4 | **2GIS** | Доступная среда (пандус), парковки, отдельная аудитория рейтинга | низкая |
| 5 | **Google поиск** | Discovery всех источников (Zoon, DocDoc, соцсети) | низкая |
| 6 | **Соцсети** (Instagram/VK) | Реальные фото пациентов/процедур, недавние акции | средняя |

## Запуск

Минимальный вход — одно из:

- Yandex Maps URL клиники (рекомендуется — золотой источник)
- Название + город
- Старый сайт клиники

Скрапинг Yandex Maps по org-ID:

```bash
node scripts/scrape-yandex-maps.js <yandex_org_id> ./research
```

Парсинг прайс-листов:

```bash
python3 scripts/parse-prices-xlsx.py ./research/prices ./research/prices/all_prices.json
```

Загрузка изображений по списку URL:

```bash
python3 scripts/download-images.py <urls.json> <output_dir> [prefix]
```

## Что на выходе

```
research/
├── clinic_data.json          # консолидированные данные (реквизиты, врачи, особенности)
├── reviews_yandex.json       # ~100 уникальных отзывов с Я.Карт
├── photos_yandex.json        # URL ~50 фото с Я.Карт
├── images-yandex/            # скачанные фото (XXXL разрешение)
├── images-old-site/          # фото со старого сайта
├── doctors-prodoctorov/      # фото врачей (low-res, backup)
└── prices/
    ├── *.xlsx                # оригинальные прайс-листы
    └── all_prices.json       # распарсенные цены
```

Стоимость прогона: AI-агент (Sonnet через Playwright) — ~30 минут, ~80–100K токенов, ~$1.5–3 на клинику. Ручной скрап — ~3–4 человеко-часа.
